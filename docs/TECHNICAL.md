# 기술 설명

## 디스크
- CD MODE2/2352 단일 트랙, ISO9660. 주요 파일: `SLPS_201.78`(실행 파일), `VOLUME.DAT`(게임 데이터, 디스크 마지막 파일), `MOVIE/*.PSS`, `SOUND/GZMVS.RBB`.
- 결과물은 2,048 바이트 섹터 ISO 로 다시 씁니다(`tools/isobuild.py`).

## VOLUME.DAT
- 헤더 `FADEBABE`, 항목 1,079개, 항목 24바이트 빅엔디언(해시, 오프셋, 크기, 0, 끝, 이름 길이+1), 데이터 기준 0x17800, 2,048 정렬.
- 이름 해시: 대문자화, `/`→`\`, `h = h*19 + c`.
- 바뀐 파일은 원래 슬롯(다음 파일 시작 전)에 넣습니다. 아카이브 끝에 붙이면 부팅이 멈추는 현상이 있어, 모든 수정 파일이 원래 슬롯에 들어가게 번역 길이를 조정했습니다.

## 대사
- 평문 스크립트(SJIS). `"..."` 안의 문자열을 `$Say`, `$SetTalkSelect` 등이 표시합니다. `\n` 줄바꿈, `@NNN` 음성 번호, `%s` 이름 삽입.
- 한글 음절은 글꼴의 한자 슬롯(0x889F~)에 순서대로 배정하고 띄어쓰기용 좁은 공백 글리프를 따로 둡니다.

## 글꼴
- `font/Samurai.fnt`: SJIS 범위표 → 포인터표 → 8바이트 레코드(x, y, 장, 비트층, 폭, 높이), 범위 밖 한자 42개용 보조 표(코드, 포인터).
- `font/Samurai.pim`: 512×512 4bpp 2장, 각 4bpp 픽셀을 2bpp 두 층으로 나눠 씀(4단계 회색). 글자 간격 = 폭+1px, 전각 공백 22px.
- 원본 저장 데이터의 기본 이름 「名無し侍」 코드 4개는 예약 글리프(「이름」「없는」「무」「사」)로 그려 「이름없는무사」로 보이게 합니다.

## 실행 파일 문자열
- 메뉴·메모리 카드·이름 표 등. 원래 바이트 길이 안에서 제자리 교체, 이름 입력 표는 한글 음절로 채움.

## 그림 글자 (PIM)
- 0x30 바이트 항목(0x13 이미지, 0x14 CLUT). 데이터는 PSMCT32 로 업로드된 것을 PSMT8/PSMT4 로 읽는 GS 메모리 배치(`tools/gsmem.py`).
- 한 텍스처에 8bpp 그림과 4bpp 글자가 섞여 있습니다. 4bpp 글자는 원본 글자에서 '가장자리→중심' 색 번호 순서를 학습해 그 순서로 한글을 칠합니다(`tools/images.py`). 8bpp 그림은 기존 팔레트로 양자화합니다(`tools/images8.py`).
- 엔딩 자막은 세로쓰기 다열 렌더링.
